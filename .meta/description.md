Adds 'Restart + Load' and 'Save + Restart + Load' buttons to the in-game menu. Restarts the game and reloads your current save, optionally saving first without an overwrite prompt.

### Restart + Load
Restarts the game without saving the current game and reloads the current game

### Save + Restart + Load
Saves the current game without an overwrite warning, restarts the game and reloads the saved game.
