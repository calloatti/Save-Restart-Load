<p>Adds 'Restart + Load' and 'Save + Restart + Load' buttons to the in-game menu. Restarts the game and reloads your current save, optionally saving first without an overwrite prompt.</p>
<h3 id="restart-load">Restart + Load</h3>
<p>Restarts the game without saving the current game and reloads the current game</p>
<h3 id="save-restart-load">Save + Restart + Load</h3>
<p>Saves the current game without an overwrite warning, restarts the game and reloads the saved game.</p>
